# Sources

Every file saved for the RAT emulation research, with origin URL and SHA1 (`shasum`, SHA-1).
Retrieved 2026-10-06 with `curl` (GitHub files via `gh api … -H "Accept: application/vnd.github.raw"`).
Entries added 2026-10-09 (the Holmes, Solomon, AN-29, Werner and Qucs papers, the MIT LM108/OP07 datasheets, the Dirk Hendrik trace,
the jazzcaster, kanengomibako, righto, AES, Holmes companion, PedalPCB, freestompboxes and DIYstompboxes pages, the two GitHub repos and
`private/docs/web/images/`) were retrieved on 2026-10-09 with `curl` and a browser User-Agent, several through the Wayback Machine
(`web/<timestamp>id_/` raw copies; the row's URL says so). Exception: `private/docs/web/forums/pedalpcb_rat-2.txt` and its raw HTML come
from a direct fetch made on 2026-10-08 by an earlier research session. Files ending `.en.md` are English summaries written for this study.
PDFs have a `pdftotext -layout` twin (`.txt`) next to them. Files marked (derived) were rendered or cropped locally.
`private/docs/photos/` (panel images; it has its own `sources.md`), `docs/panel*` and `private/reference/nam/` are maintained separately and are not listed here.

Paths are relative to the machine folder (`machines/rat/`; `private/` is its link to the private store). Re-check with: `cd machines/rat2 && shasum <path>`.
