# Fonts

The 1984 RAT's legends (DISTORTION, FILTER, VOLUME) are screen-printed Helvetica Bold capitals. The
view stands in **Nimbus Sans Bold** (URW++, the Helvetica design), each legend fitted to its measured
ink box (`docs/panel.json`, `labels`). The bar and the key list use IBM Plex Mono
(`third_party/fonts`).

The URW base 35 fonts are AGPL-3.0, Lemus's own licence (with an exception for embedding in
PostScript and PDF documents); the Xpander uses the Narrow cut from the same release.
