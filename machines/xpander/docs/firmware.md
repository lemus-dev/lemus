# Oberheim Xpander: the digital side

The real firmware runs: main processor 1.2 (`exp1.2-0..3`, U8-U5) and voice processor 1.4
(`ca1.4-0/1`, U912/U914), on two ported MC6809 cores (`core/m6809/`, from MAME, BSD-3; the opcode
switch is generated by `tools/port_m6809.py`). Both CPUs run at their 2 MHz E clock (8 MHz from
the processor board's divider, research.md 2), interleaved with the analog voices one analog sample
(about 10 bus cycles) at a time. Sources: research.md sections 4-6 (service manual SM p8-36, p39-57;
MAME `xpander.cpp`, `xpander_vb.cpp`), and the ROMs' disassembly.

## Main board (`core/mainboard.*`)

| Address | What | Model |
|---|---|---|
| $0000-$3FFF | RAM0/RAM1 (U2, U3), write-protected by MEMORY PROTECT | battery RAM, the session's state |
| $4000-$5FFF | RAM2 (U4), never protected | battery RAM |
| $6000-$63FF | DISP*/DISPCLR*: anode latch by A0-A2, grid A3-A8 when A0-A2 = 5 | the shown pattern per display and digit |
| $6400 | INTSET*: the 40103's preset | FIRQ every preset+1 counts of 250 kHz (the firmware writes 110: 2.25 kHz) |
| $6800 | HALTSET*: HALTREQ0* (bit 0), RES* (bit 4) | halts and resets the voice CPU |
| $6C06/7 | 6850 ACIA | 31.25 kbaud, 640 E cycles a byte both ways; RX/TX IRQ |
| $7000 | DATAIN: HALTAKN*, memory protect, cassette | |
| $7400, $7C80 | LED2, LED1 latches (active low) | |
| $7C00/$7C40 | encoders' direction and moved flip-flops; reading DIR* clears the moved flags | |
| $7CC0, $7D00 | GATE inputs, PULL latch | nothing plugged: each input reads its pull |
| $7D40-47 | the 8 x 8 switch matrix by column | |
| $7D80-8F | CV mux and ADC0804 | CV1-6 unplugged read 0 V; pedals unplugged read full scale (ECO 601) |
| $8000-$9FFF | ROM0, or the voice board's RAM while HALTAKN* | |
| $A000-$FFFF | ROM1-3 | |

FIRQ is cleared by the acknowledge cycle with A3 = 0 (the FIRQ vector); its assertion also blanks
the display (DISPCLR*). The VFD text is read through main ROM 1.2's font table: 16-bit anode
patterns at $B955 + 2 x character, little-endian (found by matching the boot prompt's patterns).

## Voice board (`core/voiceboard.*`)

| Address | What | Model |
|---|---|---|
| $0000-$7FFF | U917 6264 (CS = A15), mirrored | |
| $8000/$8400/$8800 | LATCH0/1/2 per voice (74LS42 outputs 0-5 = voices 6..1) | MDAC; waveforms, sync, FM routing; filter mode, noise, pan |
| $8C00-$8FFF | the DAC: CLEAR* (A0 = 0) and VOICEN* (A0 = 1) writes | S&H select/deselect events with the DAC voltage, stamped with the bus cycle |
| $9000 | DATAOUT: HALTDS, AUTOST (GATE0), PW* (GATE2 = PW* OR OSC), AUTO* (MUTE) | |
| $9400 | DATAIN: AUTODNE* (= OUT0), OSC | |
| $9800-$9803 | 8253 | CLK0 = OSC (falling edges from the analog side, sub-sample timed), CLK1/CLK2 = 2 MHz, GATE1 = NOT OUT0; OUT2's rising edge sets the IRQ flip-flop, cleared by the acknowledge |
| $A000-$BFFF | U909 (empty socket) | reads $FF |
| $C000-$FFFF | U912, U914 | |

HALTAKN* is the halted CPU's BA (the bus released at the end of an instruction), not the request
itself. The 8253 (`core/pit8253.*`) is our own from Intel's data sheet; its counters are brought up
to date at every access, so the tuning counts are exact to the bus cycle.

The DAC chain computes U813's output at each VOICEN* write (research.md 4.2): normal mode
code/16384 x 4.86 V; high resolution code/16384 x REF_T plus the fine sample / 3.01 minus
0.5747 REF_T, REF_T = 3.43 x the voice's CEM3374 temperature sensor; ECO 609's 422K offset; the
+5.0 V clamp. The fine sample (C805) and the reference (C806) are taken as instant: each is 0.022 uF
charged through a 4053/4051 [C: instant]. The firmware gives them time (bus timing logged from
voice 1.4 with a note held): each fine sample (FTSH) stays connected 33 us (VCOF1, VCOF2) or 26 us
(VCFF), and before the normal-mode writes a dummy write holds the fixed reference on C806 for 30 us.
At the CD4053B's typical 125 ohm (17 V across) that is 9-12 time constants: under 0.4 cent at the
pins. At its maximum, 240 ohm, the fine sample would keep up to 0.2 % (VCOF) or 0.7 % (VCFF) of the
previous CV's fine value: up to about 8 cents of pitch and 34 cents of cut-off, depending on the CV
written before [I].

## What the firmware does that the model relies on

- **Board revision check** (voice 1.4, C6CA-C757): with the VCAs shut, OSC must stay quiet; the
  model's CEM3372 shuts at +85 mV and the LM311 input sits 2.6 mV on the quiet side, so the
  firmware picks revision D (`$1E01` = $FF), as the target unit.
- **Auto-tune**: TUNE measures each VCO, PW, resonance and VCF through OSC and the 8253 and stores
  corrections in battery RAM. A new instance is a unit after RESET MEMORY and TUNE ALL
  (`core/warm.*`), cached per model version in Lemus's application folder.
- **Factory patches** (optional): with SYSTEMX on (MASTER, MIDI, ENABLES), the firmware stores each
  single patch dump it receives (F0 10 02 01 00 nn ... F7) into program nn once all its bytes are
  in. A new instance sends Oberheim's FACTORY1.SYX that way after TUNE ALL, then turns SYSTEMX off
  (its default) and selects patch 00 (+, then -).
- **PW tune** times OSC's high half, so it settles the absolute polarity at U108: only an output
  current against the input current in the CEM3372's final VCA lets it pass.
- **DAC MONO** (SERVICE; SM p35: "no or very seldom beep"). The main CPU starts it through voice
  RAM: `$1E24` = 1 and the command `$1E25` = 6 pick entry 6 of the table at $E9A3 (dispatcher E988),
  F19E. Clearing `$1E24` stops it (F4DA). The setup is the tune's (EB17: waveforms and MDAC off,
  LATCH2 $6C, PIT counter 0 mode 1, counter 1 mode 0). Voice 1 gets VCA, VOL A and PW2 at full,
  VOL B 0 and PW1 1.71 V (FAST). Then 16 steps (F1D8): VCO 1's S&H written in normal mode with
  FAST ($8D16/$8D17), codes 10245 to 10260, one LSB a step (0.30 mV at VCOF1, about 0.46 cent, VCO 1
  near 8.5 kHz). Each step opens the bus to the main CPU for 10 ms (F4C8: HALTDS off), writes the
  code, and 13 us later starts the count: 64 OSC periods gate counter 1, about 14600 counts. The
  S&H stays selected through the count; the next CLEAR* is the next step's, 18 ms later.
  It beeps (F259: DATAOUT $09, AUTO* opens the outputs for about 25 ms) when:
  - the first count is below the last (F22C);
  - one of the 14 steps between counts 2-16 goes backwards (F249);
  - a step is at least (first - last)/16 + 7 counts (F24B);
  - OSC stops (2800 polls, F1F9/F208).
  The first step (count 1 to 2) is not checked. A sweep takes 0.30 s and a step is about 4 counts,
  so the S&H has to hold the new voltage from the moment it is selected. Steps measure 2-6 counts
  on the model: the 8253's own quantisation, one count at each end of each count.

## Not emulated

- Cassette interface (in and out), the CV and gate inputs as plugin jacks (they read as unplugged),
  the pedals.
- Voice board revisions before D (the S&H order of the drawing is a switch for later).
