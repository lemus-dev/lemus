# Fonts

The panel's print is a condensed Helvetica-style grotesque (docs/panel.md, "Fonts"). The view stands
in **Nimbus Sans Narrow Regular** (URW++, the Helvetica Narrow design), each legend fitted to its
measured ink box, as the Xpander does (machines/xpander/fonts/README.md says why not Liberation Sans
Narrow: GPL v2, which doesn't mix with Lemus's AGPL-3.0). The bar and the key list use the host's IBM
Plex Mono (`third_party/fonts`).
