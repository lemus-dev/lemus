{NAME} for Windows
==================

{NAME}.vst3   the plugin. Copy the whole {NAME}.vst3 folder to
              C:\Program Files\Common Files\VST3
              then rescan plugins in your DAW.
{NAME}.exe    the same instrument as a standalone app.

ROMs: Lemus ships no ROM data. A machine that runs better with its ROM says
so in the bar above its panel, which shows your ROM folder (by default
%APPDATA%\Lemus\ROMs) and can change it. Put your own dump there, loose or in
a zip (MAME's sets work as they are).
